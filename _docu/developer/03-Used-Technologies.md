# Used Technologies

This document lists the technologies used in the PluginHost application.

## Backend

- **.NET 8**: The backend is built with .NET framework.
- **ASP.NET Core**: The backend uses ASP.NET Core for building the web API.
- **Entity Framework Core**: The backend uses Entity Framework Core for data access.
- **SignalR**: The backend uses SignalR for real-time communication with the frontend.
- **AutoMapper**: The backend uses AutoMapper for object-to-object mapping.
- **FluentValidation**: The backend uses FluentValidation for validating the incoming requests.
- **Keycloak**: The backend uses Keycloak for authentication and authorization.
- **MinIO**: The backend uses MinIO for storing the plugin files and list of available plugins.
- **NUKE**: The build process is automated with NUKE.
- **Docker**: The application is containerized with Docker.

## Frontend

- **React**: The frontend is built with the React library.
- **TypeScript**: The frontend is written in TypeScript.
- **Vite**: The frontend is built with the Vite build tool.
- **Tailwind CSS**: The frontend uses Tailwind CSS for styling.
- **React Router**: The frontend uses React Router for routing.
- **React OIDC Context**: The frontend uses React OIDC Context for authentication.
- **ESLint**: The frontend uses ESLint for linting the code.
